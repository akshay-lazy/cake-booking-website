# 🎂 Cake Booking Website

A global cake delivery platform with international artisan sourcing, cold-chain logistics, and corporate gifting solutions.

## Features

### Homepage
- **Hero Section**: High-converting headline with global delivery/freshness messaging
- **Value Proposition Banner**: Fresh Cold-Chain Logistics, Local Artisan Sourcing, Guaranteed On-Time Delivery
- **Best Sellers & Regional Specialties**: Global favorites with localized creations
- **Corporate & Event Gifting**: International business gifts and large-scale celebrations

### Technology Stack
- Frontend: React/Next.js
- Styling: Tailwind CSS
- State Management: React Context/Redux
- Backend: Node.js/Express
- Database: MongoDB
